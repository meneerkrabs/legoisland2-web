# Unused and hidden content of LEGO Eiland 2 (Dutch build): inventory for a "developer corner"

Read-only research pass of 2026-10-29 (no source file changed). Goal: a "The Cutting Room Floor" style list of everything the original executable and its data contain that normal play never
reaches, plus a proposal for exposing it in the port's debug mode (`src/game/debug.ts`, `?debug=1`) as an **Ontwikkelaarshoek** screen.
Sources: the Ghidra decompile (`basdebeer-tools/decomp-le2/LE2.c`, `LE2.asm.txt`, `atlas.md`), the x86 emulator of the port (free camera run), the 39 game archives (22,831 members, all
extracted once and cross-referenced), the loose audio under `_data/sounds`, the port's own set-up emulation (`extractZone`, `emulateIslandSetup`), the existing docs under `docs/re/**`, and
public sources (cheat lists, the cosideci.com modding blog, the GitHub repository LegoIsland2Reversing, GPL-3.0: used as reference only, nothing copied).

Legend. **Stars** = how interesting for players: 1 = curiosity, 2 = worth a look, 3 = would delight someone. **Proposal** = how the debug mode could expose it. **UNCERTAIN** = not settled.
Evidence is an address (`FUN_xxxxxxxx` / `DAT_xxxxxxxx` of the NL build), a file, or the method used.

Contents: 1 Summary (top 15, proposed screen) | 2 Corrections to earlier docs | 3 Known cheats and secrets | 4 New from the blog and the LegoIsland2Reversing repo | 5 Debug mode "fly like the station master" |
6 Unused code and debug paths | 7 Unused data (models, textures, animations, sounds, music, speech) | 8 Unused story and game content | 9 Method, confidence, how to reproduce.

## 5. Debug mode "fly like the station master"

### 5.1 What the original does (SUPE, `SupaStat.c`)

Node ctor `FUN_0053c337`, handler table 0x8eb0f0 `{update 0x53adc3, pre-render 0x53c25a, destroy 0x53c526, draw 0x53c29d, save 0x53c2fe, load 0x53c2d9}`, attached to record SUPE (45) in every era (its SGMFIG and Turn2Pep nodes are gated by var 0xa8).
Docs: `docs/re/m4/wp14-supe.md`, `docs/re/m4/wp5-pizza.md`.

* **Trigger** (`FUN_0053adc3`): surface under Pepper `DAT_009da9ac` == 9 (rail), or == 10 with the locomotive (TRNL, var `DAT_00983804+0x408c`) within 32 (`_DAT_008925e8` = 1024 squared); SUPE state < 5; Pepper's y strictly between 41 and 48 (`_DAT_008925e4` / `_DAT_008925e0`); the tick timer (node +0x50) must reach 3.0 (`_DAT_00892200`), forced to 4 if the loco is within 24. Not conditional on the skateboard.
* **Call:** nearest track node (`FUN_0053a41b`, 10 ROAD nodes at 0x8eb114) and nearest helipad exit node (`FUN_0053a4f7`). If |Pepper x - x of ROAD 0x67| < 24 and the display is not 16-bit (`DAT_00987660`) he flies the whole east line (states 9/10/0xb). If SUPE is out of view he appears 24 behind the camera, 8 up (`FUN_0053a6c2`); within 1600 of the camera he swoops from where he is.

## 6. Unused code and debug paths in the EXE

Method: a sweep over all 5,140 functions of the decompile building a reference set (call/jmp targets, `push`/`mov imm` of function addresses, data dwords in `.data`/`.rdata` = vtables and callback tables, root = `entry`):

## 7. Unused data
